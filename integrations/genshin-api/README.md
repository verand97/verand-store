# Integrasi Genshin Impact API

Titik integrasi untuk validasi UID Genshin & data akun (AR, region, karakter).
Implementasi memakai `TopupService::validateUid('genshin-impact', ...)`.

Env: `GENSHIN_API_URL` (kosong = stub). Untuk top-up Genesis Crystal dan
verifikasi server (Asia/America/Europe/TW-HK-MO).
